Student Management System

A simple React-based Student Management System built using JavaScript, HTML, and CSS.

Features

- Add Student
- View Students
- Update Student
- Delete Student

Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

How to Run the Project

1. Download or clone this repository.

2. Open the "frontend" folder.

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL shown in your terminal.
