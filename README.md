Student Management System

A simple React-based Student Management System built using JavaScript, HTML, and CSS.

Features

- Add Student
- View Students
- Update Student
- Delete Student

Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

How to Run the Project

1. Open the "frontend" folder.
2. Run "npm install".
3. Run "npm run dev".
4. Open the local URL shown in the terminal.
